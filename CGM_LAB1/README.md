# CGM Lab Assignment 1 – Basic Graphics Primitives

## Aim
To write a C++ program using the graphics library to draw basic graphics primitives in a single program.

## Objective
To understand and implement basic graphics primitives using C++.

## Software Requirements
- C++ Programming Language
- Visual Studio Code
- MinGW/G++ Compiler
- WinBGIm Graphics Library (`graphics.h`)

## Graphics Primitives
1. **Straight Line** – Drawn using the `line()` function.
2. **Circle** – Drawn using the `circle()` function.
3. **Rectangle** – Drawn using the `rectangle()` function.
4. **Triangle** – Drawn by connecting three straight lines.

## Functions Used
- `initgraph()` – Initializes graphics mode.
- `line()` – Draws a straight line.
- `circle()` – Draws a circle.
- `rectangle()` – Draws a rectangle.
- `getch()` – Waits for a key press.
- `closegraph()` – Closes the graphics window.

## How to Run
1. Open `CGLab1.cpp` in VS Code.
2. Make sure the graphics library is configured.
3. Compile and run the program using the configured Run button.
4. A graphics window will display all four shapes.

## Output
The program displays a straight line, circle, rectangle, and triangle in a single graphics window.
